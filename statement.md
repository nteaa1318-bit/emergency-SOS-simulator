# Problem Statement

## Problem

During an emergency situation, important information such as the type of emergency, severity, and location needs to be collected and processed quickly.

Manual handling of emergency information can lead to delays, incomplete information, or incorrect processing.

Therefore, there is a need for a simple software-based system that can simulate the process of receiving and handling an emergency SOS request.

## Proposed Solution

The Emergency SOS Simulator is a Python-based application that simulates an emergency response workflow.

The system allows the user to:

- Select an emergency type.
- Enter the severity of the emergency.
- Provide the emergency location.
- Validate the entered information.
- Process the emergency request.
- Simulate an appropriate response.
- Generate an SOS alert.
- Save the incident details.
- View previously recorded incidents.

The project is divided into multiple modules so that different responsibilities are handled seperately.

## Expected Outcome

The system should successfully accept valid emergency information, reject invalid inputs, simulate the emergency response, generate an SOS alert, and maintain an incident history.

The project is intended for educational and demonstration purposes and does not connect to real emergency services.

## Scope of the Project

The project focuses on simulating the basic workflow of an emergency SOS system.

The scope includes collecting emergency information, validating user input, processing emergency requests, simulating responses, generating SOS alerts, and maintaining incident history.

The project does not include real communication with police, fire departments, hospitals, or other emergency services.

## Target Users

The intended users of this project are:

- Students learning Python programming ans software development.
- Developers studying modular application design.
- Users who want to understand the basic workflow of an emergency respomse system.
- Evaluators who want to demonstrate and test an emergency-response simulation.
